simplezip.
Static JSON · No API key · No backend

US ZIP code data.
Nothing complicated.

Look up US ZIP codes with simple, predictable JSON files. City, state, county, coordinates, and more — available directly over HTTPS.

Direct file format: us/{zip}.json

Example response · /us/83845.json
{
  "postalCode": "83845",
  "city": "Moyie Springs",
  "state": "Idaho",
  "stateCode": "ID",
  "county": "Boundary",
  "countyCode": "021",
  "latitude": 48.7464,
  "longitude": -116.1796,
  "accuracy": 4
}
Simple URLs

Each ZIP code has its own JSON file. No SDK or API key needed.

Static hosting

Files are served directly from GitHub Pages, without a running backend.

Useful fields

Locality, state, county, and estimated geographic coordinates.

Data sourced from GeoNames (US postal code dataset), licensed under CC BY 4.0. Data converted to JSON and field names adapted. Coordinates are estimates and may not represent ZIP boundaries.
